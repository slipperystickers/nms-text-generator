# NMS Text Generator for Blender Base Builder — v1.6.0

## What's new

- **Vector:** a fifth complete A–Z / 0–9 panel-lettering style, with a visual
  preview, flat-capped diagonals, a softer D, and the corrected C return terminals.
- **Fewer parts:** Vector's `TYNDUSTRIAL ASTRONAUTICS` example now uses **367
  panels**, down from 555 in the private development build. Vector uses 4–32
  panels per character. All exposed faces remain parallel; no tilted-face trick.
- **Tighter spacing:** compact I spacing and refined optical spacing around Y.
- **Panel type selector:** choose **Flat Panels** or **Storage Panels (back)**
  for any of the five styles. Storage uses its plain back face. Changing panel
  type keeps the design and part count, with native proportions and uniform scaling.
- **Easy re-editing:** panel type is saved per sign and works with auto-switch,
  right-click Edit NMS Text, undo/redo, save/reopen, and native JSON export.
- **Expanded instructions:** the complete guide covers both panel types, updates,
  and hiding Blender's connection lines without breaking the text grouping.

Boundary, Bulkhead, Orbit and Forge remain available with their existing saved-file IDs.

## Install or update

1. Download **NMS_Text_Generator_1.6.0.zip** below. Do not use the automatically
   generated Source code archives as the Blender installer.
2. Install/enable the compatible **No Man's Sky Base Builder** first.
3. In Blender, open **Edit > Preferences > Add-ons > menu > Install from Disk**,
   select the ZIP without extracting it, and enable the text generator.
4. Save your work and **restart Blender** after updating. Press **N** over the
   3D Viewport and open the separate **NMS Text** tab; its label should show v1.6.0.

[Read the complete user guide](https://github.com/slipperystickers/nms-text-generator/blob/v1.6.0/USER_GUIDE.md).

Existing signs are **not rebuilt automatically** by installing the update. To use
the updated Vector recipes, select one panel, right-click **Edit NMS Text**, and
confirm **OK**. Keep a backup first: rebuilding replaces manual panel edits.
Old signs default to Flat Panels until you explicitly change their panel type.

Tip: hide the dotted control connections using **Viewport Overlays > Objects >
Relationship Lines**. Do not unparent the panels or delete the text control.

## Validation and requirements

- Clean installer tested with **Blender 5.1.2 on Windows** and the development
  **Base Builder 18.0.8** installation.
- All five alphabets tested with both native panel types, including native export,
  automatic switching, selection safeguards, edit/cancel, undo/redo and save/reopen.
- Ten standalone layout tests and clean-ZIP Blender integration tests passed.
- Base Builder supplies the native assets separately; the optional Storage mode
  requires its `STORAGEPANEL` asset. No game meshes, textures, font files, or
  reference Blender scenes are bundled.
- In-game loading speed, console and unmodded multiplayer behavior are not
  certified. No claim that one panel type loads better than the other.

The installer includes the full guide, changelog, license and attribution notices.
**SHA256SUMS.txt** is provided to verify the download.
