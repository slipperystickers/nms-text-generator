## Base Builder and No Man's Sky

This add-on calls **No Man's Sky Base Builder**, created by **DjMonkey**, as a
separately installed dependency. No Base Builder source is bundled. The tested
installation declares GPL-3.0-or-later and supplies the native assets at runtime.

Base Builder project: https://www.nexusmods.com/nomanssky/mods/984

No Man's Sky and its game assets belong to **Hello Games** and their respective
rightsholders. This repository contains part IDs and placement data, not game
meshes or textures. Preview PNGs depict the resulting in-game parts as rendered
in Blender; this project's code license does not grant rights to underlying game art.

## Lettering styles

The layouts are NMS panel-placement recipes rather than installable font software.
Bulkhead, Orbit and Forge were developed as custom geometric panel alphabets.
Boundary was developed with **Future Z by Darrell Flood / Hawtpixel** as an
explicit visual reference and then adjusted for NMS parts and construction limits.
It was formerly displayed as Future Z during development. The new name does not
assert independent authorship of that referenced design, endorsement, or permission
from its author. No Future Z font file is included.

Reference and author's terms: https://www.dafont.com/future-z.font

Those terms restrict redistribution/reformatting of the reference font; this
project does not purport to relicense that font or override third-party rights.
Do not infer permission to extract a general-purpose font from this project.

Compatibility IDs (`FUTURE_Z`, `INDUSTRIAL`, `ORBITAL`, `FOUNDRY`) and preview
filenames retain development names so previously saved signs remain editable.

Vector (`VECTOR`) uses **Orbitron by The Orbitron Project Authors** as a visual
baseline, with user-requested adaptations based on a supplied handmade ship-title
reference. The panel recipes include custom letter forms and construction
approximations; the Vector name does not claim authorship of Orbitron or endorsement.
The reference font's copyright notice identifies Copyright 2018 The Orbitron
Project Authors and Reserved Font Name "Orbitron", under SIL Open Font License 1.1.
No Orbitron font file, extracted font outlines, or reference screenshot is bundled.

The supplied handmade Tyndustrial lettering by Tyrellixx also informed Vector's
C return terminals and the optional Storage Panel back-face construction. The
supplied Blender scene is not bundled in the add-on.

Reference project: https://github.com/theleagueof/orbitron

Reference source and license: https://github.com/google/fonts/tree/main/ofl/orbitron
